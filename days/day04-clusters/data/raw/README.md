`cdot_hin_2025.csv` lists CDOT's High Injury Network corridors as printed in the *Chicago Traffic
Crashes Annual Report* (published Fall 2025), p. 13: one row per street, with the cross streets that
end it. The report does not publish the network as data. The `street`, `from` and `to` columns use
the street names in the map data (OpenStreetMap); `|` separates alternatives (Austin is an avenue on
the Chicago side and a boulevard on the city line). Milwaukee Ave ends at Leavitt St, and corridor 1 is
split where Broadway meets Sheridan Rd.
